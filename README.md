# Personal Browser

A real Chromium desktop browser for everyday search and browsing.

## Run

```bash
npm install
npm start
```

Requires Node.js. First launch downloads Chromium via Electron.

## Use

- Type a URL or a search in the address bar (Google)
- Tabs: `Ctrl+T` new, `Ctrl+W` close
- `Ctrl+L` focus address bar, `Ctrl+R` reload
- `Ctrl+D` bookmark, `Ctrl+H` history
- Back / forward: toolbar or `Alt+←` `Alt+→`

Bookmarks and history are saved on your computer.
